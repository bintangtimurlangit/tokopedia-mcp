# Tokopedia MCP documentation

**Tokopedia MCP** is a [Model Context Protocol](https://modelcontextprotocol.io/) server for **public discovery** on [Tokopedia](https://www.tokopedia.com): product search with full dynamic filtering, product detail, customer reviews, and shop info — over **stdio**, for Cursor, Claude Code, Claude Desktop, and other MCP hosts. No login required.
